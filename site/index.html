Features

一个 IM 该有的，都在这里

从连接接入到消息落库，每一层都可独立替换与扩展。

双协议接入

WebSocket 与基于 gnet 的原生 TCP 并行，Protobuf 二进制编码，心跳保活与断线重连。

单聊与群聊

群组创建、加入、退出与成员通知，群消息扇出投递，@ 提及成员。

离线消息

在线实时推送、离线 Redis 队列暂存，重新上线后自动补拉，消息去重与 ACK 确认。

消息撤回

两分钟内撤回已发送消息，跨网关与离线用户同步撤回通知。

已读与未读

已读回执实时回传，会话未读数精确统计，多端状态一致。

富媒体

图片、视频、文件、语音与贴纸表情；RustFS 对象存储，自动生成图片缩略图。

全文搜索

按关键字检索历史消息，游标分页，客户端 ⌘/Ctrl+F 快速唤起。

多网关集群

一致性哈希路由用户，gRPC 跨节点转发，Redis 服务发现与健康检查自动摘除故障节点。

Architecture

分层架构，按需伸缩

接入层只管连接与路由，持久化通过 Kafka 异步完成，热路径不被存储拖慢。
